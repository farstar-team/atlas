# نصب، مدیریت و رفع مشکل

## ورود از گوشی و کامپیوتر

از نسخهٔ 0.2.0 لینک عمومی هنگام نصب نمایش داده می‌شود. نمونه:

```text
https://panel.example.com:9786/secret/atlas/
```

حتی بازکردن `https://panel.example.com:9786/` تو را به مسیر درست هدایت می‌کند. برای استفاده از پنل، روی دستگاه کاربر SSH یا CMD لازم نیست.

ورود مثل پنل ضریب از حساب ثنایی استفاده می‌کند. با ورود قبلی در همان مرورگر و همان دامنه/IP، صفحه مستقیم باز می‌شود. در دستگاه تازه نام کاربری و رمز ثنایی را وارد کن؛ اگر ورود دومرحله‌ای فعال است کد همان حساب را هم بده. Atlas رمز و کد را ذخیره نمی‌کند. خروج از Atlas کوکی مشترک ثنایی را در همین آدرس پاک می‌کند.

## آدرس عمومی، HTTPS و گواهی

نصب‌کننده آدرس‌ها، مسیر و گواهی پنل فعلی را پیدا می‌کند. اگر ZARIB نصب باشد، فقط تنظیمات وب آن را می‌خواند؛ در غیر این صورت فقط تنظیمات وب دیتابیس محلی ثنایی را به‌صورت خواندنی بررسی می‌کند. اجرای روزمرهٔ Atlas به دیتابیس دسترسی ندارد.

IPهای عمومی شناخته‌شده هم پذیرفته می‌شوند. برای HTTPS بدون اخطار مرورگر، آدرسی را باز کن که گواهی پنل آن را پوشش می‌دهد. گواهی مختص دامنه معمولاً خود IP را پوشش نمی‌دهد؛ Atlas گواهی جدید صادر نمی‌کند. اگر پنل اصلی HTTP باشد، Atlas همان حالت را حفظ می‌کند.

کپی محدود گواهی و کلید در `/etc/farstar-atlas/tls` و تنظیم دسترسی در `/etc/farstar-atlas/access.json` قرار می‌گیرند. این فایل‌ها متعلق به root هستند. سرویس `farstar-atlas-certificates.timer` هر پنج دقیقه کپی را بررسی می‌کند؛ تغییر معتبر TLS بدون restart خود Atlas بارگذاری می‌شود. دسترسی و محتوای فایل‌های اصلی گواهی تغییر نمی‌کند.

برای تعیین آدرس یا پورت دلخواه هنگام نصب/به‌روزرسانی:

```bash
ATLAS_SOURCE_DIR=/path/to/atlas bash /path/to/atlas/install.sh --host panel.example.com --web-port 9786
```

به‌روزرسانی معمول با همان دستور آنلاین README است؛ به SSH forward یا برداشتن تنظیم HTTPS نیازی ندارد. سلامت‌سنج نصب از همان پورت و گواهی استفاده می‌کند. پورت قبلی Atlas تا وقتی صریحاً پورت دیگری نداده‌ای حفظ می‌شود.

## نصب خصوصی اختیاری

اگر خودت حالت قدیمی را می‌خواهی، هنگام نصب `--private` بده. در این حالت آدرس `127.0.0.1:9786` و رمز مستقل Atlas حفظ می‌شوند. برای تغییر رمز این حالت:

```bash
runuser -u farstar-atlas -- atlas password
systemctl restart farstar-atlas
```

در نصب عمومی، رمز از ثنایی مدیریت می‌شود و این دستور رمز ورود عمومی را تغییر نمی‌دهد.

## وضعیت سرویس و توکن مدیریت مسیر

```bash
systemctl status farstar-atlas --no-pager
journalctl -u farstar-atlas -n 50 --no-pager
```

Activeبودن سرویس به معنی سالم‌بودن خروجی کشورها نیست. اتصال واقعی را از اشتراک تحویل‌شده به گوشی آزمایش کن.

توکن Admin در «اتصال و بازیابی» برای مدیریت مسیرهای افزونه است؛ با ورود مرورگر فرق دارد. داشتن این توکن، جای ورود حساب ثنایی را نمی‌گیرد. اگر توکن را حذف یا منقضی کردی، همان‌جا توکن تازه بده. توکن مانیتور و node-sync برای تغییر routing کافی نیستند. خالی‌گذاشتن فیلد یعنی حفظ توکن قبلی.

## پورت‌ها و فایروال

| محدوده | کاربرد |
|---|---|
| `0.0.0.0:9786` | مدیریت عمومی با ورود ثنایی؛ در صورت اشغال، پورت آزاد جایگزین |
| پورت انتخابی `1024–60999` | ورودی تازهٔ همان کشور، باید از کاربر قابل دسترسی باشد |
| `127.0.0.1:61101–61132` | پل داخلی خروجی؛ عمومی نکن |
| `127.0.0.1:61201–61232` | SOCKS داخلی Psiphon؛ عمومی نکن |
| `127.77.0.1–32` | آدرس داخلی اتصال به اینباند فعلی؛ IP کاربر نیست |

نصب‌کننده فایروال را flush یا غیرفعال نمی‌کند. پورت کشور را فقط در صورت نیاز باز کن. اگر فایروال سفارشی یا Fail2ban مستقل قبلاً آدرس داخلی Atlas را مسدود کرده، فقط همان آدرس داخلی را از همان محدودیت خارج کن؛ کل jail را خاموش نکن. Atlas اجازهٔ بومی پنل را خودکار اضافه می‌کند.

## اگر مسیر ساخته نشد

پورت تازه باید آزاد باشد. موتور Psiphon باید نصب شده باشد. API لازم و توکن Admin باید پاسخ بدهند. اگر اینباند فقط روی IPv6 گوش می‌کند، یک ورودی TCP روی IPv4 انتخاب کن.

اگر پشتیبان هم وجود ندارد، «در دسترس نیست» درست‌تر از نمایش اتصال ساختگی است. خطای موتور را با نصب دوبارهٔ فایل بررسی‌شده و دسترسی شبکهٔ سرور بررسی کن. انتخاب کشور به معنی موجودبودن آن در شبکهٔ ارائه‌دهنده نیست.

## عملیات نیمه‌تمام و بازیابی

اگر ارتباط با پنل وسط تغییر قطع شود، Atlas تلاش می‌کند فقط منابع خودش را برگرداند. اگر این کار هم ممکن نشود، نوار هشدار می‌بینی. ابتدا ارتباط پنل را برگردان و از تنظیمات **بازیابی عملیات نیمه‌تمام** را بزن.

برای اجرای همان بازیابی از SSH، وقتی سرویس متوقف است:

```bash
systemctl stop farstar-atlas
runuser -u farstar-atlas -- atlas recover
systemctl start farstar-atlas
```

پشتیبان‌ها در `/var/lib/farstar-atlas/backups` هستند و اطلاعات حساس پنل را دارند. آن‌ها را عمومی نکن. بازیابی UI تعریف مسیرهای Atlas را برمی‌گرداند؛ رمز فعلی Atlas، کاربران و تغییرهای مستقل امروز پنل را به نسخهٔ قدیمی برنمی‌گرداند.

## منابع سرور

هر مسیر Psiphon یک فرایند جدا دارد. تعداد زیاد کشورها RAM و CPU بیشتری می‌خواهد؛ از چند کشور لازم شروع کن و مصرف واقعی را ببین. سقف انتشار اول ۳۲ مسیر و حدود ۲۰۴۸ اتصال هم‌زمان در لایه‌های relay است؛ این عدد تضمین ظرفیت یا سرعت نیست. هر اتصال کاربر می‌تواند هم ورودی و هم خروجی relay مصرف کند.

همهٔ این مسیرها همچنان به همین سرور پنل وابسته‌اند. تنوع کشور خروجی به معنی چند دیتاسنتر مستقل یا حذف نقطهٔ شکست مشترک نیست.
